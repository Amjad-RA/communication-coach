# Communication Coach

A single-page HTML communication coach. Open `index.html` in any browser — no install needed.

- **Home** – skill modules (English Communication is live; more coming).
- **English Practice** – 30 daily 10-minute sessions (Beginner 1–10, Intermediate 11–20, Advanced 21–30). Each day card shows the topic, goal, useful words and the full coaching prompt.
- **Gemini button** (right side of each card) – copies the day's prompt and opens Gemini with it. If Gemini's chat box is empty, just paste and send.
- **Mark as done** – progress is saved in your browser.

To add or edit days, change the `DAYS` list in `index.html`.
